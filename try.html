Before you start

Small host toolchain.
No host OS inside the guest.

QEMU, Rust and image-building tools exist only on the development host. After UEFI hands off the machine, ORYVAEL is the guest operating system.

Networking

The NAT is created by QEMU.

You do not need to create a Windows NAT, Linux bridge, macOS bridge, TAP adapter or Internet Connection Sharing for the recommended test path.

Why bind to 127.0.0.1?

The forwarded SSH port is reachable only from the host itself. Do not change the bind address to an external interface for this research image.

01

Windows 10 / 11

Build with WSL.
Run QEMU natively.

Windows keeps the GUI and SSH client native. WSL is used only for the portable image build tools.

1

Install host prerequisites

Run an elevated PowerShell. A first-time WSL install requires a reboot.

PowerShell · Administrator
winget install --id Git.Git -e
winget install --id SoftwareFreedomConservancy.QEMU -e
wsl --install
Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0
WSL install ↗Windows OpenSSH ↗
2

Clone and prepare WSL build tools

PowerShell
git clone https://github.com/jellero/ORYVAEL.git
Set-Location ORYVAEL
wsl bash -c 'sudo apt-get update && sudo apt-get install -y curl build-essential dosfstools mtools && if ! command -v rustup >/dev/null 2>&1; then curl --proto "=https" --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y; fi'
3

Create your SSH administrator key

The private key remains in .oryvael\oryvael_admin. The build embeds only its public key.

PowerShell
New-Item -ItemType Directory -Force .oryvael | Out-Null
cmd.exe /d /s /c 'ssh-keygen -q -t ed25519 -N "" -f .oryvael\oryvael_admin -C oryvael-admin'
4

Build the image

PowerShell → WSL build
wsl bash -c '. "$HOME/.cargo/env" && ./scripts/build-os.sh'

dist\oryvael-x86_64-uefi.img is now ready for Windows QEMU.

5

Launch QEMU + create NAT

PowerShell
.\scripts\run-os.cmd -NetworkMode User -DisplayMode Gui

The launcher keeps the VGA/GOP device enabled and creates 127.0.0.1:2222 → guest:22.

6

Connect with SSH

Open a second PowerShell in the ORYVAEL repository.

PowerShell
ssh -i .\.oryvael\oryvael_admin -p 2222 admin@127.0.0.1
PORT 2222 BUSY?.\scripts\run-os.cmd -NetworkMode User -DisplayMode Gui -SshHostPort 2223ssh -i .\.oryvael\oryvael_admin -p 2223 admin@127.0.0.1

Troubleshooting

Three checks cover most failures.

PORT

Is 2222 already used?

Choose 2223 or another free host port with --ssh-port / -SshHostPort.

KEY

Permission denied (publickey)

Generate .oryvael/oryvael_admin.pub, rebuild the image, then connect with the matching private key.

FIRMWARE

OVMF/EDK2 not found

Install the documented QEMU/OVMF package, or set OVMF_CODE and OVMF_VARS explicitly on Unix hosts.
